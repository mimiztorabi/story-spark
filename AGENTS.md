# Repository Guidance

<!-- This file explains how contributors should work in this portfolio case-study repository. -->

## Purpose

This is a beginner-friendly, public **portfolio case study** for a Senior Product Manager. It is not a production service. Keep contributions legible to non-engineering reviewers and clearly distinguish demonstrated work from placeholders or assumptions.

## Content guidelines

- Use plain English, short headings, and explain acronyms at first use.
- Mark unverified research, metrics, names, and decisions as **[Placeholder]**.
- Do not add API keys, secrets, tracking, backend services, databases, paid services, or external dependencies.
- Preserve the prototype as static HTML, CSS, and JavaScript that can be hosted on GitHub Pages.
- Keep safety and privacy considerations visible when changing AI-related content.

## Prototype guidelines

- Use semantic, accessible HTML and keyboard-operable controls.
- Do not fetch remote resources or submit data anywhere.
- Keep the simulated AI behavior deterministic and label it as a simulation.
- Put any manually exported prototype images in `assets/prototype-screens/` and document them.

## Quality check

Before committing, inspect the diff and open `prototype/index.html` locally to confirm that the static interaction works without a build step.
