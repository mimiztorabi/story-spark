# Evaluation Plan

## Decision to inform

Should Story Spark invest in a caregiver-reviewed, constrained story-idea experience rather than an open-ended child-facing chat experience?

## Learning goals

1. Determine whether caregivers understand the review step.
2. Identify whether bounded choices feel helpful or restrictive.
3. Test whether the output format feels appropriate for a shared activity.
4. Find safety language that increases clarity without causing unnecessary alarm.

## Decision rules

- Advance only if participants consistently identify the caregiver review step.
- Revise if bounded inputs are confusing or output feels too generic.
- Pause if safety reviewers identify high-severity risks that cannot be mitigated through constrained design.
